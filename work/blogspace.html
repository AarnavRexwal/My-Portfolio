BlogSpace

What a request goes through

Follow the dot: a reader opens a post.

What it does

Readers browse posts by category, search, page through results and leave comments. Writers sign in and create, edit and delete their own posts, with image uploads.

The choices I’d explain in an interview

  • JWT for sign-in.The API is stateless, so the React app on Vercel and the API on EC2 only need to share a token.
  • Database on RDS, not on the server.The API server can be rebuilt without touching the data.
  • Nginx in front.It terminates HTTPS and forwards to Spring Boot, so the app itself never handles certificates.
  • Swagger docs.Every endpoint can be tried in the browser, which helped me test before the frontend existed.

What I’d do next

Add tests around the comment and permission rules, and give the site a proper title and icon instead of the default Vite ones.
